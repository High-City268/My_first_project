How it works

MEEP turns student recruitment into a repeatable, visible process by aligning agents, administrators, and applicants on the same platform.

1. Register applicants

Agents add student profiles, capture key details, and begin the document collection process.

2. Verify documents

Admins and agents check passports, transcripts, and certificates before advancing each application.

3. Submit applications

Once completed, applications are reviewed, approved, and shared with students for next steps.
